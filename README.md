# 终极井字棋（Ultimate Tic-Tac-Toe）

一个纯前端实现的「终极井字棋」网页小游戏，没有框架、没有构建工具，打开就能玩。

## 玩法

整张棋盘是一个 3×3 的大棋盘，每个大格子里又藏着一片 3×3 的小井字格，一共 9 片。

核心规则只有一条，但要动点脑筋：

- **你下在哪，对方就去哪片**：你落在小棋盘的第几格，就决定对手下一步必须去大棋盘相同位置的那一片。
- **那片满了或已经分出胜负**：对手就可以任意选择任何还没结束的棋盘落子。
- **连成三子，赢下一片小棋盘**。
- **连成三片，赢下整场游戏**。

## 功能

- 双人对战
- 人机对战（简单 / 中等 / 困难三档难度）
- 新手教程（动态关卡 + 文字解说，一步步带你熟悉规则）
- 落子后的棋盘高亮提示、悬停预览、胜负/平局判定

## 运行

直接双击 `index.html` 在浏览器里打开即可，无需安装任何依赖。

## 技术栈
